# 🦜 초롱이 — 시니어를 위한 실시간 아바타 말동무

어르신이 앵무새 캐릭터 **초롱이**와 목소리 또는 글로 대화하는 웹 서비스입니다.
초롱이는 대화 내용의 감정을 읽어 **표정과 몸짓을 바꾸고**, 실제 목소리 파형에 맞춰 **입(부리)을 움직입니다.**

---

## 1. 설치

```bash
npm install
```

## 2. API 키 넣기

`.env` 파일은 이미 만들어져 있습니다. 메모장으로 열어 키만 붙여 넣으면 됩니다.

```bash
notepad .env
```

파일 안에서 이 줄을 찾아

```
OPENAI_API_KEY=
```

`=` 바로 뒤에 키를 붙여 넣고 저장(Ctrl+S)하세요.

```
OPENAI_API_KEY=sk-proj-여기에본인키
```

- 따옴표(`" "`)를 붙이지 마세요
- `=` 앞뒤에 띄어쓰기를 넣지 마세요
- **`#` 으로 시작하는 줄(설명 줄)에는 넣지 마세요** — 그 줄은 서버가 읽지 않습니다
- 키는 <https://platform.openai.com/api-keys> 에서 발급하며, **만든 직후 한 번만** 보여 줍니다

제대로 들어갔는지는 서버를 켤 때 나오는 `✅ API 키 확인 완료` 문구로 알 수 있습니다.
키가 없으면 웹 화면 맨 위에도 노란 안내 막대가 뜹니다.

> 키는 서버에서만 읽습니다. 브라우저로는 절대 전달되지 않으며, 모든 OpenAI 호출은 서버가 대신합니다.
> `.env`는 `.gitignore`에 등록되어 있어 깃에 올라가지 않습니다.

## 3. 실행

```bash
npm start
```

브라우저에서 <http://localhost:3000> 을 엽니다.

> 음성으로 말하려면 **크롬 또는 엣지**를 권장합니다(브라우저 실시간 음성인식 사용).
> 다른 브라우저에서는 녹음 후 서버가 받아쓰는 방식으로 자동 전환됩니다.

## 시니어를 위한 화면 설계

디자인은 장식을 걷어낸 **차분하고 단정한 방향**입니다.
얇은 테두리(1px), 절제된 색(짙은 초록 하나만 강조색), 넉넉한 여백, 선으로 그린 아이콘을 씁니다.
글씨 크기와 대비는 크게 유지하되 알록달록한 요소는 쓰지 않습니다.

- **글자 크기 3단계** (보통 / 크게 / 아주 크게) — 선택하면 다음에도 유지됩니다
- **모든 버튼 높이 40px 이상**, 마이크·보내기 버튼은 54px
- **큰 자막** — 소리가 잘 안 들려도 초롱이 말을 읽을 수 있습니다
- **천천히 말하기** — 말 속도를 늦춥니다
- **소리 끄기** — 조용한 곳에서는 글자로만
- **다시 들려주세요** — 방금 한 말을 반복
- **추천 문장 버튼** — 무슨 말을 할지 막막할 때 눌러서 시작
- 상태를 색과 글자로 함께 안내 (듣고 있어요 / 생각하고 있어요 / 말하고 있어요)

## 회상 대화

어르신이 사진을 보며 옛 기억을 이야기하시도록 돕는 기능입니다.
설계는 `회상대화_알고리즘` 문서를 따랐습니다.

**핵심은 질문을 참는 것입니다.** 질문이 이어지면 대화가 아니라 기억력 검사처럼
느껴지고, 어르신이 스스로 이야기를 이어가시려는 순간에 말을 끊게 됩니다.
그래서 초롱이는 되짚기 · 공감 · 요약을 먼저 하고, 이야기가 멈췄을 때만 묻습니다.

| 어르신 상태 | 초롱이 반응 | 질문 |
| --- | --- | --- |
| 위험 · 응급 표현 | `SAFETY_FLOW` 안전 안내 | 안 함 |
| 아직 이야기 이어가는 중 | `BACKCHANNEL` 짧은 맞장구 | 안 함 |
| 감정을 직접 말씀하심 | `VALIDATE_EMOTION` 감정 인정 | 안 함 |
| 새 사건 · 사람 · 장소 | `REFLECT_CONTENT` 한 문장 되짚기 | 안 함 |
| 한 이야기가 마무리됨 | `SUMMARIZE` 한 문장 요약 | 안 함 |
| 말씀이 멈춤 | `FOLLOW_UP` 질문 하나 | **함** |
| 불편 · 피로 | `OFFER_CHOICE` 선택 제공 | 선택만 |

**질문 예산은 코드가 강제합니다.** 프롬프트로만 부탁하면 모델이 결국 질문을
덧붙이기 때문입니다. `server.js` 의 `questionBudget()` 이 지난 이력을 세어
이번 차례에 물어도 되는지 정하고, 대답이 온 뒤 `limitQuestions()` 가
규칙을 어긴 질문 문장을 걷어냅니다.

- 두 번 연속 질문하지 않습니다.
- 한 주제(최근 여섯 발화)에서 회상 질문은 최대 세 개입니다.
- 다만 **종료 선택과 안전 안내의 물음은 걷어내지 않습니다.**
  여기서 자르면 어르신이 대화를 그만둘 길이 막힙니다.

**없는 사실을 말하지 않게** 프롬프트에는 `verified_fields` 에 있는 항목만
들어갑니다. 화면은 `memory_id` 만 보내고 내용은 서버가 직접 찾습니다.
어르신이 새로 말씀하신 내용은 확인 전까지 `UNVERIFIED` 주장으로만 쌓입니다.

### 사진 등록

`/memories.html` 에서 보호자가 사진과 생애정보를 등록합니다.
등록한 항목만 `verified_fields` 에 들어가고, 빈 칸은 대화에 쓰이지 않습니다.

### 사진 보며 이야기하기

대화 화면 위쪽 **사진 이야기** 를 누르면 시작됩니다.

1. 서버가 사진 한 장을 고릅니다 (미검증 · 감춤 · 불편 표시한 사진은 제외)
2. 사진과 제목을 띄우고 "어떤 일이 가장 먼저 떠오르세요?" 하고 한 번만 여쭙니다
3. 이후는 평소 경청 규칙대로 되짚고 공감합니다
4. **그만 보기** 나 **다른 사진** 을 누르면, 오늘 새로 들은 이야기를 보여 드리고
   기억으로 남길지 여쭙니다

### 새로 들은 이야기는 확인 뒤에 저장합니다

음성인식이 잘못 알아듣거나 모델이 잘못 새겨들은 내용이 사실로 굳으면, 다음
대화부터 초롱이가 그 틀린 이야기를 사실처럼 말하게 됩니다. 그래서 대화 중
나온 새 내용은 곧바로 저장하지 않습니다.

- 대화 중 나온 새 이야기는 `UNVERIFIED` 주장으로만 쌓입니다. 프롬프트에
  들어가지 않으므로 초롱이가 아직 사실처럼 말하지 않습니다.
- 회기가 끝날 때 어르신께 보여 드리고 여쭙습니다.
- **남기겠다** 하시면 `VERIFIED` 가 되어 다음 대화부터 쓰입니다.
- **아니요** 하셔도 지우지 않고 `UNVERIFIED` 로 그냥 둡니다.
  지워 버리면 나중에 보호자가 살펴볼 길이 없어집니다.
- 여쭙는 것은 **이번 회기에 들은 것만** 입니다. 지난번에 답을 못 받은 이야기까지
  한꺼번에 물으면 오늘 하지도 않은 말을 왜 묻느냐가 되고, 서로 어긋나는 값이
  나란히 확정될 수 있습니다.

대화 기록은 `SESSION` 으로 따로 남습니다. `/api/sessions/metrics` 로 질문 대비
되짚기 비율, 연속 질문 횟수 같은 지표를 볼 수 있습니다.

## 어디가 아프다고 하실 때

"병원에 가 보세요" 한마디로 넘기지 않습니다. 급한 정도에 따라 셋으로 나눠 대합니다.

| 단계 | 신호 | 초롱이가 하는 일 |
| --- | --- | --- |
| 응급 | 가슴 통증 · 숨참 · 쓰러짐 · 말이 어눌함 · 한쪽 팔다리에 힘이 없음 · 갑작스런 심한 두통 | 다른 말 없이 **119** 안내 |
| 오늘내일 진료 | 열이 계속 · 점점 심해짐 · 아파서 잠을 못 잠 · 다친 뒤 붓고 못 디딤 · 며칠째 안 나음 | 공감 뒤 오늘 중 병원 권유, 가족 연락 돕기 |
| 흔한 불편 | 무릎 시큰함 · 허리 뻐근함 · 소화 불편 · 가벼운 두통 | 공감 + 편해질 만한 것 한두 가지 + 병원에 가셔야 할 때 |

말씀드려도 되는 것은 **누구에게나 안전한 생활 속 이야기**뿐입니다.
무리하지 마시고 쉬시라는 말, 따뜻하게 하시라는 말(다치신 직후라면 차게),
물 자주 드시라는 말, 천천히 일어나시라는 말 같은 것들입니다.

절대 하지 않는 것 — 병명 짐작, 약 이름이나 용량, 복용량 조절, 낫는다는 약속,
병원에 안 가셔도 된다는 말, 민간요법이나 건강식품 권유.

아플 때는 상태를 여쭤도 됩니다. "언제부터 그러셨어요?"는 기억력 검사가 아니라
걱정에서 나오는 물음이라 회상 질문 예산에 넣지 않습니다. 다만 한 번에 하나만
여쭙고, 이때만 백오십 자까지 씁니다.

## 목소리를 아이 목소리로 만드는 방법

OpenAI 음성 합성에는 음높이 조절 기능이 없습니다. 그래서 이렇게 우회합니다.

1. 서버가 `VOICE_PITCH` 배만큼 **느리게** 음성을 만들도록 요청합니다
2. 응답 헤더 `X-Voice-Pitch` 로 그 값을 브라우저에 알려 줍니다
3. 브라우저가 그 배속으로 **빠르게** 재생합니다

말 속도는 원래대로 돌아오고 **음높이만 올라가서** 어린아이 목소리가 됩니다.
너무 높다고 느끼시면 `.env` 의 `VOICE_PITCH` 를 `1.10` 정도로 낮추세요.

## 캐릭터 세 명

| 캐릭터 | 성격 | 목소리 |
| --- | --- | --- |
| **초롱이** | 다정한 앵무새. 아이처럼 밝게 재잘거립니다 | `nova` + 음높이 1.16 |
| **준호** | 손주 같은 이십 대 청년. 씩씩하고 살갑습니다 | `ash` (청년 남성) |
| **서연** | 손녀 같은 이십 대 청년. 상냥하고 세심합니다 | `coral` + 음높이 1.04 |

화면 위 **친구 바꾸기** 버튼으로 언제든 바꿀 수 있고, 선택은 브라우저에 저장됩니다.
목소리는 서버에서만 정하므로 브라우저가 임의의 목소리를 요청할 수 없습니다.

세 캐릭터는 부위 이름(`ch-eye-l`, `ch-beak-lower` …)을 똑같이 쓰고,
좌표 차이만 `geom` 에 따로 적어 두어 감정·립싱크 코드를 그대로 공유합니다.

## 캐릭터에 대해

초롱이의 겉모습은 납작한 벡터 그림체(둥근 사각형 몸, 큰 흰자 눈, 작은 노란 부리)를 따르되,
앵무새다운 볏과 갈고리 부리, 색깔 날개 끝으로 초롱이만의 생김새를 갖도록 그렸습니다.
다른 회사의 마스코트를 그대로 옮기지 않았으므로 실제 서비스에 그대로 쓰셔도 됩니다.

## 아바타 손보기

`public/avatar.js` 안에서

- `C` — 색상표 (몸 색, 부리 색 등)
- `SVG` — 초롱이의 생김새. 부위마다 `id`가 있어 각각 움직입니다
- `EMOTIONS` — 감정별 표정 수치 (눈썹 각도, 눈꺼풀, 볏 기울기, 볼, 눈물 등)

표정을 바꾼 뒤 <http://localhost:3000/expressions.html> 에서 한 번에 확인할 수 있습니다.
